## How this project is built

This project is built hands-free, with speech (FluidVoice) and an 8BitDo Micro, as a test for a blog post. The build itself is the data.

- Keep the mapping from keys to buttons and actions in one pure module with tests. The drawing reads from it.
- Prefer small steps that each end in something the maintainer can see or run. Many short approvals are the point; one huge change is not.
- Ask questions as multiple choice where you can. Those are answered with the D-pad and A.
- Ask before pushing or creating anything on GitHub.
